The public marketing page for **I Send You E2E Text**.

Canonical website: [www.isyeet.io](https://www.isyeet.io/). This mirror serves the page directly; it does not redirect or claim a custom domain.

Contains static HTML, CSS and development screenshots with fictional data. No messaging service, app source, account data or credentials are included.

Publish this directory as the GitHub Pages source root. Its site base path is `/`; no build step or dependencies are required.
